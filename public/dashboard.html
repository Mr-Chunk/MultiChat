7 Add it to OBS

  1. In OBS, click + under Sources → Browser → name it “MultiChat”.
  2. Paste the URL above into URL (leave “Local file” unchecked).
  3. Set Width 400 and Height 600, then click OK and position it.
You only do this once. Everything you change on this page — themes, fonts, colors, backgrounds — shows up in OBS instantly, and chat appears by itself whenever you go live. Keep this link private: anyone with it can show your overlay.
